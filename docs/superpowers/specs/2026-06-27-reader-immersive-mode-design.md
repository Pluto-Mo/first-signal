# 阅读器沉浸式模式设计

日期：2026-06-27

## 1. 目标

把当前“章节切换 + 常驻右栏”的阅读器，改成更接近长文阅读的沉浸式模式。

本次目标只解决 3 件事：

- 报告正文按整篇文章连续展示，不再依赖章节 tab 切换。
- 引用面板默认收起，点击引用后再以右侧抽屉方式唤起。
- 句尾引用标签缩小一档，弱化工具感。

## 2. 已确认决策

- 采用 `C` 方案：正文主场 + 引用抽屉。
- 保留现有本地文档包数据结构，不重做 reader bundle。
- 不新增页面，不扩到原文页、搜索、路由改造。

## 3. 现状问题

- 正文区当前只能一次读一个 section，阅读动作是切 tab，不是连续向下阅读。
- 常驻右侧栏长期占据视觉空间，会不断提醒用户“这是工具页”，削弱长文沉浸感。
- 引用标签尺寸偏大，和正文正文层级过近，容易打断视线。

## 4. 设计方案

### 4.1 阅读主区

- 所有 `sections` 按顺序直接渲染成一篇长文。
- 保留 section 标题，作为文内层级，而不是导航控件。
- 每个 block 继续使用现有 `lead / finding / note` 语义样式，但整体排版更偏长文。

### 4.2 引用交互

- 默认不显示 citation/source 右栏。
- 用户点击正文中的 citation chip 后，右侧抽屉滑出。
- 抽屉中继续显示：
  - 引用编号和摘要
  - 质量状态
  - 摘录
  - 本地定位字段
- 抽屉应支持关闭，关闭后回到只看正文的状态。

### 4.3 版式结构

- 文档列表保留在顶部，但弱化成更轻的条状区块，不抢主视觉。
- 正文容器宽度扩大，成为页面视觉中心。
- 当抽屉未打开时，正文宽度最大化；抽屉打开时，正文适度收缩但仍保持主要面积。

### 4.4 引用标签

- citation chip 字号、padding、图标尺寸同时下调。
- 视觉上更接近“句尾脚注标记”，而不是可操作按钮块。
- 选中态保留，但高亮不应压过正文。

## 5. 实现边界

- 不修改后端 `reader_bundle.json` 结构。
- 不新增 markdown 原文预览模块。
- 不在本次引入目录抽屉、滚动定位或搜索能力。

## 6. 验收标准

- 打开文档后，默认看到的是整篇连续文章，而不是 section tab。
- 点击任一引用标签后，右侧抽屉出现并显示正确 citation 内容。
- 关闭抽屉后，页面回到正文优先模式。
- 引用标签视觉尺寸明显小于当前版本。
